# WebStandards Watch

Scrapy-парсер публичного [каталога стандартов и черновиков W3C](https://www.w3.org/TR/).
Собирает короткий идентификатор, название, статус зрелости, ссылку и дату публикации.
Карточки каталога уже содержат нужные поля, поэтому страницы всех документов не загружаются.
Повторы ссылок исключаются; неизвестные статусы сохраняются как есть.

Автор адаптации и доработок — Рябуха Олег.

## Запуск

Python 3.11. Команды для PowerShell из каталога проекта:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m scrapy crawl standards
.\.venv\Scripts\python.exe -m pytest
```

В Linux/macOS используйте `python3.11`, `.venv/bin/python`.
База данных, миграции, токены и `.env` не требуются.
`.env.example` документирует отсутствие обязательных переменных.

Результаты в `results/`:

- `standards_<дата>.csv`: `identifier,name,status,url,published`;
- `status_summary_<дата>.csv`: количество документов для каждого статуса и `Total`.

CSV записываются в UTF-8. Каждый запуск создаёт новую пару файлов.
Парсер соблюдает robots.txt, делает один запрос к каталогу и не обходит архивы публикаций.
Если карточки исчезнут или обязательные поля изменятся, паук завершится с сообщением
`check selectors`; причину остановки нужно проверить в логе Scrapy.

## Проверки и источник

`tests/fixtures/w3c_catalog.html` — три карточки реального каталога, сохранённые
17 ноября 2026 года. Сетевых запросов во время тестов нет.
Тесты проверяют извлечение полей, ошибки при пустой странице, два CSV через настоящий
Scrapy crawler и совпадение итогов сводки с количеством документов.
В `results/` сохранена проверочная выгрузка реального запуска; подробности в `REVIEW.md`.
